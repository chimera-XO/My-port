# NEX Portfolio (v4 — Rotated Fullscreen Portrait Video)

Monochrome glassmorphism portfolio with an isometric vault box unlock (5 taps), full-screen rotated background video on mobile portrait screens, and detailed semi-transparent 2D SVG icons.

## Run in Termux

```bash
unzip /storage/emulated/0/nexus-portfolio-v4.zip -d nexus-portfolio-v4
cd nexus-portfolio-v4
npm install
npm run dev
```
